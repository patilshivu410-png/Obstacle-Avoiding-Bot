-->OBSTACLE AVOIDING BOT

## 📌 Description

This project uses 8 ultrasonic sensor and 2 esp32 to detect and avoide obstacles.

## 🛠️ Components Used

* ESP32 (2x)
* Ultrasonic sensors (8x)
* LM2596 (buck converter)
* L298N (motor driver)
* A four wheel car chassis
* 4 motors
* li-ion battery

-->⚙️ Features

* 360° obstacle detection using multiple ultrasonic sensors
* Autonomous navigation with real-time decision making
* Dual ESP32 architecture for sensor processing and motor control
* Dynamic path selection to avoid collisions
* Low-cost and scalable embedded system design

--> Challenges

* Managing interference between multiple ultrasonic sensors
* Ensuring accurate distance measurements
* Synchronizing communication between two ESP32 modules
* Stabilizing power supply for consistent performance

## ✅ Outcome

Successfully developed a working prototype capable of detecting obstacles and navigating autonomously in real time.
